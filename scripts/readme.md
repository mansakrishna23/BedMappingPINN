Scripts for training the PINNs and pre-processing the data with ISSM. Files included are: 
- **experiment.py** : for training the PINNs
- **validation.py** : for the three PINN validation experiments (The files that are used are "ValidationTracks_15km.mat", "ValidationTracks_30km.mat" and "ValidationTracks_60km.mat" corresponding to each experiment).
- **resampled.py** : for training the PINNs with resampling of collocation points. 
- **preprocessing.m** : for pre-processing the data and saving it in an ISSM model.
